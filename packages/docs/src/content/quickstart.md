# Quick Start

Get FingguFlux up and running in minutes.

## 1. Installation

Install the core engine and your preferred adapter:

```bash
npm install @finggujadhav/core @finggujadhav/react
```

## 2. Configure the Compiler

Add the FingguFlux compiler to your build pipeline (e.g., `vite.config.ts`):

```typescript
import { fingguCompiler } from '@finggu/compiler';

export default {
  plugins: [
    fingguCompiler({
      mode: 'dev', // 'dev', 'opt', or 'ext'
      include: ['./src/**/*.{tsx,ts}']
    })
  ]
}
```

## 3. Initialize Provider

Wrap your application in the `FingguProvider`. This injects the mapping generated by the compiler.

```tsx
import { FingguProvider } from '@finggu/react';
import mapping from './finggu-mapping.json';

function App() {
  return (
    <FingguProvider mapping={mapping} mode="dev">
      <YourApp />
    </FingguProvider>
  );
}
```

## 4. Use Components

Use hardened components with full type safety.

```tsx
import { Button } from '@finggu/react';

export default function Welcome() {
  return (
    <Button variant="primary" motion="pop">
      Get Started
    </Button>
  );
}
```

## Choosing Your Mode

| Mode | Selector Format | Best For |
| :--- | :--- | :--- |
| **Dev** | `ff-btn-primary` | Rapid debugging and inspection. |
| **Optimized** | `btn-primary` | Production with readable source. |
| **Extreme** | `ff-xz2` | Maximum minification and obfuscation. |
