CSS Drift Demo

Witness how FingguFlux prevents silent style breakage by enforcing design contracts between tokens and components.

Traditional CSS Drift-Prone

Tokens are loosely coupled. Renames/removals go unnoticed.

$ npm run build
Building assets...
Build completed in 1.4s (0 errors)
// Note: Variable --primary-color was renamed to --brand-color
// but .btn-primary still points to old variable.
⚠️ SILENT FAILURE: Button style broke because token name changed. No CI error was thrown!
FingguFlux Contract-Safe

Tokens are registered. Removals trigger CLI breakage.

$ npx finggu snapshot --compare
Analyzing theme contracts...
✅ No drift detected. All tokens are valid.
🛡️ CONTRACT ENFORCED: CLI detected the attempted removal and blocked the build.
