# FingguFlux Roadmap

The following roadmap outlines the evolution of FingguFlux from its current Public Beta (v0.9.0) towards a v1.0 stable release and beyond.

## 🟢 Phase 1: Public Beta (Current)
*Focus: Stability and Parity*
- [x] Hardened React, Vue, Svelte adapters.
- [x] Deterministic hashing engine (Extreme Mode).
- [x] Scoped theme isolation.
- [x] Centralized token registry.

## 🟡 Phase 2: Tooling & Integrations (Q2 2026)
*Focus: DX and Ecosystem*
- [ ] **Official Vite Plugin**: Streamlined setup for ESM projects.
- [ ] **Tailwind-to-Finggu Bridge**: Utility to migrate Tailwind layouts to Finggu tokens.
- [ ] **Next.js / Nuxt / SvelteKit Optimized Meta-Adapters**: Deeper integration with meta-frameworks.
- [ ] **Finggu Lint**: ESLint plugin to enforce Finggu architectural constraints (no raw hex, no ID styling).

## 🔵 Phase 3: Advanced Hardening (Q3 2026)
*Focus: Security and Scale*
- [ ] **Cross-Build Mapping Stability**: Guaranteed hash stability across independent project builds.
- [ ] **Visual Test Scanner**: Automatic verification that compiled CSS perfectly matches source intentions.
- [ ] **Zero-JS Mode**: A specialized mode for hyper-static environments with absolutely no runtime requirement.

## 🟣 Phase 4: v1.0 Stable (End of 2026)
- [ ] Full API stability.
- [ ] Comprehensive component library (Forms, Data Tables, Charts).
- [ ] Enterprise-grade performance benchmarks.
